# Sources and credibility assessment

## Tier 1 — Primary / standards

### W3C WAI — Making Events Accessible: presentations
- URL: https://www.w3.org/WAI/teach-advocate/accessible-presentations/
- Authority: W3C Web Accessibility Initiative; primary accessibility guidance.
- Currency: Current WAI resource; page content references WCAG and modern remote/hybrid event patterns.
- Relevant findings: Limit text per slide; make text and visuals large enough for the back of the room; use easy-to-read fonts; provide sufficient contrast; describe relevant visual information; provide accessible material in advance; HTML material should meet WCAG at least Level AA.
- Bias: Standards/advocacy, non-commercial.
- Reliability: Tier 1.

### W3C WCAG 2.2 Understanding SC 1.4.3 Contrast (Minimum)
- URL: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- Authority: W3C WCAG Understanding documentation.
- Currency: WCAG 2.2 current understanding doc.
- Relevant findings: Normal text/images of text require 4.5:1 contrast; large-scale text requires 3:1; logos are exempt; anti-aliasing/thin fonts may appear fainter, so best practice is to exceed thresholds.
- Bias: Standards, non-commercial.
- Reliability: Tier 1.

### W3C WCAG 2.2 Understanding SC 1.4.11 Non-text Contrast
- URL: https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html
- Authority: W3C WCAG Understanding documentation.
- Currency: WCAG 2.2 current understanding doc.
- Relevant findings: Meaningful graphical objects and UI component indicators require 3:1 contrast against adjacent colors. Important for diagram connectors, icons, chart lines, focus indicators, and boundaries.
- Bias: Standards, non-commercial.
- Reliability: Tier 1.

### W3C WCAG 2.2 Understanding SC 1.4.1 Use of Color
- URL: https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html
- Authority: W3C WCAG Understanding documentation.
- Currency: WCAG 2.2 current understanding doc.
- Relevant findings: Color cannot be the only visual means of conveying information; pair color with text, shape, pattern, position, or contrast.
- Bias: Standards, non-commercial.
- Reliability: Tier 1.

### W3C WCAG 2.2 Understanding SC 1.3.1 Info and Relationships
- URL: https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html
- Authority: W3C WCAG Understanding documentation.
- Currency: WCAG 2.2 current understanding doc.
- Relevant findings: Relationships conveyed by presentation should be programmatically determined or available in text. Use semantic HTML, headings, lists, tables for data, labels, captions, and text descriptions where needed.
- Bias: Standards, non-commercial.
- Reliability: Tier 1.

## Tier 2 — Mature design-system guidance

### GOV.UK Design System — Colour
- URL: https://design-system.service.gov.uk/styles/colour/
- Authority: UK government design system.
- Currency: Active public design system; explicitly references WCAG 2.2 contrast minimum.
- Relevant findings: Use functional colors consistently; text and interactive elements must meet WCAG 2.2 SC 1.4.3 AA; avoid copying raw values when token functions are available.
- Bias: Government service design; not slide-specific but highly credible for web UI tokens.
- Reliability: Tier 2.

### GOV.UK Design System — Spacing
- URL: https://design-system.service.gov.uk/styles/spacing/
- Authority: UK government design system.
- Currency: Active public design system.
- Relevant findings: Use spacing scales rather than one-off spacing; responsive and static scales support predictable rhythm. Applicable to protected rails and component gaps.
- Bias: Government service design; not slide-specific.
- Reliability: Tier 2.

### IBM Design Language — Type basics
- URL: https://www.ibm.com/design/language/typography/type-basics/
- Authority: IBM Design Language.
- Currency: Page showed last updated 23 Apr 2026.
- Relevant findings: Good typography requires consistency, hierarchy, alignment; flush-left aids readability and information design; avoid all caps for paragraphs; control line length; use simple title/subtitle differentiation; avoid too many emphasis styles.
- Bias: Vendor brand system; broadly applicable typography principles.
- Reliability: Tier 2.

### Material Design 2 — Data visualization
- URL: https://m2.material.io/design/communication/data-visualization.html
- Authority: Google Material Design. Note: page itself states Material 2 is no longer maintained and points to Material 3.
- Currency: Legacy but still useful for data visualization principles; use cautiously.
- Relevant findings: Data visualizations should be accurate, helpful, scalable; dashboards should prioritize the most important information; presentation dashboards use curated snapshots and dynamic headlines; reinforce chart color with icons/text/shape; avoid rotated labels; use balanced axis labels; multiple colors can hinder focus.
- Bias: Vendor system; older version.
- Reliability: Tier 2 for stable visualization principles, with currency caveat.
