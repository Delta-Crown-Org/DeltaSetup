# Raw evidence extracts

- GitHub Actions notifications: if email/web notifications for Actions are enabled, users receive notification when triggered workflow runs complete; notification includes status and can be limited to failed runs. Scheduled workflow notifications route to the user who created/updated/re-enabled schedule.
- GitHub workflow status badges: badge shows whether workflow is failing or passing; default branch by default, branch/event parameters available.
- GitHub webhooks: workflow_run completed event fires when a workflow run finishes regardless of success; workflow_job completed event fires when a job finishes regardless of success. Webhook payloads include delivery IDs/signatures and support JSON delivery.
- Microsoft Purview Audit: unified audit log captures/records/retains thousands of user and admin operations across Microsoft services; Audit Standard enabled by default; Audit Standard retention 180 days for current records; Office 365 Management Activity API supports SIEM/longer retention export.
- Microsoft Entra audit logs: comprehensive report on logged Entra events; changes to applications, groups, users, licenses captured; entries are system generated and cannot be changed/deleted; details can include actor/target and old/new property values.
- Microsoft Entra app access: individual and group app assignment modes; requiring assignment prevents sign-in except explicitly assigned users/groups; if assignment not required, unassigned users may still sign in directly/SP-initiated; local-account bypass must be disabled in apps that support it.
- Microsoft Entra assignment management: group assignment does not cascade to nested groups; group-based assignment requires Entra ID P1/P2; account discovery can identify matching and local users and monitor for unauthorized access.
- Microsoft 365 audit event catalog: includes Application administration, Microsoft Entra group administration, User administration, SharePoint file/page, sharing/access request, site administration, site permissions, Teams, and Purview Audit solution activities.
- SharePoint audit caveats: FileAccessed/FileModified/PageViewed extended events reduce noise; app@sharepoint indicates application-performed activity, including compliance workflows; some client-signaled events may not be definitive intent.
- MTO guidance: tenant is an identity/access-management scope and Microsoft 365 collaboration/licensing boundary; cross-tenant access settings must be explicitly configured for each tenant relationship; MTO/cross-tenant synchronization are high-trust org-internal models; existing B2B collaboration member users in MTO tenants immediately become MTO members upon MTO creation.
- CISA SCuBA: provides M365 secure configuration baselines and ScubaGear assessment tool for tenant controls; intended for FCEB but available for all organizations.
- NIST SP 800-53 Rev. 5: control catalog includes Access Control, Audit and Accountability, Assessment/Authorization/Monitoring, Configuration Management, Identification and Authentication, Incident Response, and System/Information Integrity families.
